# エアコンカードのサイズによるグリッドレイアウト崩れを修正する

## Context

デバイス一覧は `grid grid-cols-2 gap-2` の2カラムグリッドで表示されている。エアコン（AC）カードは温度調整・モード選択（5列）・ファン速度選択（4列）を含むため、他のデバイスカードに比べて縦幅が大きい。

現状、AC カードは他のカードと同じ1カラム幅に収まっているが、隣接するカードとの高さの差が大きく、グリッド全体のレイアウトバランスが崩れている。

## Requirements

- AC カードが2カラムグリッド内で他のカードとバランスの取れたレイアウトになるよう修正する
- 方針の候補:
  1. AC カードを `col-span-2`（全幅）にして独立した行に配置する
  2. AC カード内のコントロールをよりコンパクトにする（モード・ファン速度を横並びにする等）
  3. 両方の組み合わせ
- 通常モード・並べ替えモードの両方で正常に表示されること
- ライト/ダークモードの両方で見た目が崩れないこと

## Affected Files

- `src/components/DeviceCard.tsx` — AC カードのレンダリング分岐部分（L294-311）。`col-span-2` の追加、またはカードの構造変更
- `src/components/controls/ACControl.tsx` — コントロールのレイアウト調整（コンパクト化する場合）
- `src/components/DeviceList.tsx` — グリッドレイアウトの調整が必要な場合（L199: `grid grid-cols-2`）

## Acceptance Criteria

- [x] AC カードが他のデバイスカードとバランスの取れたレイアウトで表示される
- [x] 並べ替えモード（ドラッグ&ドロップ）でも正常に動作する
- [x] ライト/ダークモードの両方で正しく表示される
- [x] AC カードの操作（電源・温度・モード・ファン速度）が引き続き正常に動作する
- [x] `bun run build` が TypeScript エラーなしで成功する

## Notes

- 現在の AC カードの構造: Header(デバイス名+電源) → 温度調整(±ボタン) → モード選択(5列グリッド) → ファン速度(4列グリッド)
- `col-span-2` にする場合、`SortableDeviceCard` のラッパー div にもクラスを伝搬する必要がある
- `getDeviceCategory()` が `'ac'` を返すのは IR エアコンデバイスのみ

# 「操作不可」チェックボックスをトグルアイコンに変更する

## Context

DeviceSettings の各デバイス行に「操作不可」チェックボックス+テキストが表示されているが、全行に表示されるため視覚的にうるさい。チェックボックス+テキストの代わりにコンパクトなトグルアイコン（ロック/アンロック等）に変更して、省スペース化と視覚的ノイズの軽減を図る。

## Requirements

- 「操作不可」チェックボックス+テキストをトグルアイコン（ロック/アンロック等）に変更する
- アイコンの状態で操作不可/操作可能が視覚的に判別できるようにする
- ホバー時にツールチップで「操作不可」/「操作可能」等の説明を表示する
- 既存の `onToggleDisabled` ハンドラはそのまま利用する
- visible=false のデバイスでは引き続き disabled 状態にする

## Affected Files

- `src/components/options/DeviceSettings.tsx` — チェックボックスをトグルアイコンに変更、ツールチップ追加
- `src/utils/i18n.ts` — ツールチップ用の翻訳キー追加（必要に応じて）

## Acceptance Criteria

- [x] 各デバイス行にロック/アンロックのトグルアイコンが表示される
- [x] アイコンクリックで操作不可/操作可能が切り替わる
- [x] ホバー時にツールチップで状態が説明される
- [x] 非表示デバイスではアイコンが disabled 状態になる
- [x] `bun run build` が TypeScript エラーなしで成功する

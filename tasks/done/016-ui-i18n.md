# UI テキストの日本語・英語対応を実装する

## Context

タスク 007 でエラーメッセージの日英対応は完了しているが、
ボタンラベル・見出し・プレースホルダ等の UI テキストはすべて英語ハードコードのまま。
既存の `src/utils/i18n.ts` の `t()` 関数を拡張し、UI 全体を日英対応させる。

## Requirements

- 既存の `t()` 関数を汎用メッセージキーに対応するよう拡張する
- 全コンポーネントのハードコード文字列を `t()` 呼び出しに置き換える
- ブラウザ言語に応じて日本語/英語を自動切替する（既存のロケール判定を流用）

## Affected Files

### i18n 基盤
- `src/utils/i18n.ts` — UI メッセージの日英マッピングを追加、`t()` を拡張

### Popup
- `src/entrypoints/popup/App.tsx` — "Loading...", "Setup Required", "Open Settings" 等

### Options
- `src/entrypoints/options/App.tsx` — "SwitchBot Controller Settings", 説明文等
- `src/components/options/ApiKeyForm.tsx` — "API Credentials", "API Token", "Save Credentials" 等
- `src/components/options/SecuritySettings.tsx` — "Security Mode", "Standard", "High Security" 等
- `src/components/options/ConnectionTest.tsx` — "Test Connection", "Connected!" 等
- `src/components/options/DeviceSettings.tsx` — "Device Display Settings", "Loading devices..." 等

### デバイス一覧・操作
- `src/components/DeviceList.tsx` — "SwitchBot", "Refresh", "Settings", "No devices found." 等
- `src/components/SearchBar.tsx` — "Search devices..."
- `src/components/UnlockPrompt.tsx` — "Locked", "Unlock", "Master password" 等
- `src/components/controls/SensorDisplay.tsx` — "Loading...", "Motion!", "Open", "Closed" 等
- `src/components/controls/ACControl.tsx` — "Mode", "Fan", aria-label 等
- `src/components/controls/LockControl.tsx` — "Confirm?", "Locked", "Unlocked"
- `src/components/controls/TVControl.tsx` — "ON", "OFF"

## Acceptance Criteria

- [x] 日本語ブラウザで全 UI テキストが日本語で表示される
- [x] 英語ブラウザで全 UI テキストが英語で表示される
- [x] 既存のエラーメッセージ i18n が引き続き動作する
- [x] `bun run build` が TypeScript エラーなしで成功する

## Notes

- `chrome.i18n` API（`_locales/` ディレクトリ）への移行は将来検討。現段階では既存の `i18n.ts` を拡張する方針
- aria-label 等のアクセシビリティ文字列も対象に含める
- 動的な文字列（例: "Connected! {n} device(s) found."）はテンプレートパラメータ対応が必要

# Popup の検索バーをトグル表示に変更する

## Context

Popup の DeviceList ヘッダーに検索バー（SearchBar）が常時表示されている。Popup の縦方向のスペースは限られており、デバイス数が少ない場合は検索バーが不要なスペースを占有している。

検索バーをアイコンボタンでトグル表示に変更し、必要なときだけ展開できるようにする。

## Requirements

- 検索バーをデフォルトで非表示にし、ヘッダーに検索アイコンボタンを追加する
- 検索アイコンボタンをクリックすると検索バーが表示される（アニメーション付き）
- 検索バー表示中に再度アイコンをクリック、または検索文字列を空にして blur すると非表示に戻る
- 検索中（検索文字列がある状態）は検索バーを自動的に閉じない
- 並び替えモード中は検索アイコンボタンも非表示にする（既存の挙動と整合）
- ダークモードに対応する

## Affected Files

- `src/components/DeviceList.tsx` — SearchBar の表示トグルロジック、検索アイコンボタンの追加
- `src/components/SearchBar.tsx` — 必要に応じて `onBlur` コールバックの追加

## Acceptance Criteria

- [ ] デフォルトで検索バーが非表示になっている
- [ ] 検索アイコンボタンで検索バーを表示・非表示できる
- [ ] 検索文字列がある間は検索バーが表示され続ける
- [ ] 並び替えモード中は検索アイコンボタンが非表示になる
- [ ] ダークモードで正しく表示される
- [ ] `bun run build` が TypeScript エラーなしで成功する

# SwitchBot API v1.1 準拠監査・修正

## Context

SwitchBot API の実装が公式ドキュメント（https://github.com/OpenWonderLabs/SwitchBotAPI）に準拠しているか監査した結果、型定義・ヘッダー・エラーハンドリング・リファレンスドキュメントの4領域で差異が見つかった。これらを修正して公式 API との整合性を確保する。

## Requirements

- `LockStatus` 型に `calibrate: boolean` フィールドを追加する
- `MotionSensorStatus` 型に `brightness: 'bright' | 'dim'` フィールドを追加する
- `ContactSensorStatus` 型に `brightness: 'bright' | 'dim'` フィールドを追加する
- `auth.ts` の Content-Type ヘッダーを `application/json; charset=utf8` に修正する
- `api.ts` の statusCode 190 エラーコードを `DEVICE_ERROR` から `SYSTEM_ERROR` に変更する
- `errors.ts` のエラーメッセージを公式ドキュメントの説明に合わせて更新する
- `docs/switchbot-api-v1.1-reference.md` を公式 API に合わせて更新する

## Affected Files

- `src/types/switchbot.ts` — LockStatus, MotionSensorStatus, ContactSensorStatus に欠落フィールドを追加
- `src/lib/auth.ts` — Content-Type ヘッダーに `charset=utf8` を追加
- `src/lib/api.ts` — statusCode 190 のエラーコード名を SYSTEM_ERROR に変更
- `src/utils/translations/errors.ts` — DEVICE_ERROR を SYSTEM_ERROR にリネーム、メッセージ更新
- `docs/switchbot-api-v1.1-reference.md` — ステータスフィールド・エラーコード説明の修正

## Acceptance Criteria

- [ ] `LockStatus` に `calibrate: boolean` が含まれる
- [ ] `MotionSensorStatus` に `brightness: 'bright' | 'dim'` が含まれる
- [ ] `ContactSensorStatus` に `brightness: 'bright' | 'dim'` が含まれる
- [ ] Content-Type ヘッダーが `application/json; charset=utf8`
- [ ] statusCode 190 のエラーが `SYSTEM_ERROR` として処理される
- [ ] エラーメッセージが公式ドキュメントの説明と整合する
- [ ] リファレンスドキュメントが修正内容を反映している
- [ ] コードベースに `DEVICE_ERROR` への参照が残っていない
- [ ] `bun run build` が TypeScript エラーなしで成功する

# 設定画面の並び替えUIを見直す

## Context

設定画面のデバイス並び替えは1列リスト（`verticalListSortingStrategy`）で表示されており、ポップアップの2列グリッドレイアウトと乖離があるため直感的でない。タスク052でポップアップの並び替えモードに非表示・操作不可のトグルが追加されれば、設定画面の並び替え機能と機能が重複する可能性がある。

検討すべき方向性:
1. 設定画面の並び替えを削除し、ポップアップに一本化する
2. 設定画面の並び替えを2列レイアウトに変更して直感性を改善する
3. 設定画面はそのまま残す（高度な設定用として）

## Requirements

- タスク052完了後に、ポップアップと設定画面の機能重複を評価する
- いずれかの方向性を選択して実装する:
  - 削除する場合: `DeviceSettings.tsx` の並び替え関連コードを削除
  - 改善する場合: 2列グリッドレイアウトに変更、`rectSortingStrategy` に切り替え
  - 残す場合: 必要に応じて改善点を対応

## Affected Files

- `src/components/options/DeviceSettings.tsx` — 並び替えUIの変更または削除

## Acceptance Criteria

- [ ] 設定画面の並び替えUIについて方向性が決定されている
- [ ] 決定した方向性に基づいて実装が完了している
- [ ] ポップアップと設定画面の間で機能の重複や矛盾がない
- [ ] `bun run build` が TypeScript エラーなしで成功する
